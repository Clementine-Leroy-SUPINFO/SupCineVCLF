# SupCineVCLF
Mini-projet de cinéma réalisé en binôme dans le cadre d'un cours sur le JavaScript. 

## Contexte pédagogique
Ce projet a été développé en réponse à la consigne suivante : "Un cinéma d'un petit village isolé souhaite proposer des films à l'affiche pour attirer plus de jeunes des villages alentours.Pour atteindre cet objectif, les gérants du cinéma décident de vous missionner pour créer une application permettant aux clients de visualiser les films disponibles." Il s'agit d'un exercice académique, sans vocation commerciale réelle.

## Stack technique
- **HTML** — structure des pages
- **CSS** — mise en forme et mise en page
- **JavaScript** — animation des pages
- Hébergement en local et en ligne via GitHub : https://clementine-leroy-supinfo.github.io/SupCineVCLF/

## Fonctionnalités principales
- **Page d'accueil** (`index.html`)
- **Page search** : page permettant de taper le nom d'un film afin de le trouver
- **Pages Movie** : une fiche détaillée par film

## Arborescence du projet
```
.
├── index.html
├── movie.html
├── search.html
├── LICENCE.txt
├── asset/
│   │   ├── components/       # footer.js, header.js, movieCardTemplate.js
│   │   ├── css/           # notre feuille de style
│   │   ├── img/           # Logo du site et notre image en cas d'absence de poster de film
│   │   ├── js/           # index.js, movie.js, search.js
│  
```

## Installation et lancement en local 
Le projet est fourni sous forme d'archive `.zip`.

1. Télécharger et décompresser l'archive
2. Ouvrir le fichier `index.html` dans un navigateur web
